PROJECT TITLE:
Hospital Patient Management System

PURPOSE OF PROJECT:
The purpose of this project is to simulate a hospital system that manages patient flow efficiently using appropriate data structures. Emergency patients are prioritized based on severity using a MinHeap, while regular patients are handled in a first-in, first-out manner using a CircularQueue. The project demonstrates how data structures can be applied to solve real-world problems involving prioritization and scheduling.

VERSION or DATE:
Version 1.0 – April 2026

HOW TO START THIS PROJECT:

1. Open the project in a Java IDE (e.g., Eclipse, IntelliJ, or VS Code).
2. Ensure all class files (Patient, MinHeap, CircularQueue, HospitalManagementSystem, PerformanceTest) are included in the same project.
3. Compile the project.
4. Run the Main class to execute the system.
5. (Optional) Run the PerformanceTest class to generate performance data.

AUTHORS:

Member 3 – Developed MinHeap and CircularQueue classes

USER INSTRUCTIONS:

* When the program runs, users can add patients to the system.
* Emergency patients are automatically prioritized based on severity level.
* Regular patients are processed in the order they arrive.
* The system processes all emergency patients before regular patients.
* PerformanceTest can be used to observe execution times for different input sizes.
